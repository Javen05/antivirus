How to run it

Download. Start the agent. Open the console.

1

Install Python 3

ClearGuard runs as a local Python agent on Windows. Python 3.11+ is recommended.

2

Start ClearGuard

Run scripts\start-clearguard.ps1 from PowerShell, or run python server.py.

3

Install persistence

Run scripts\install-clearguard.ps1 once so ClearGuard starts when you sign in.

4

Open the console

Go to http://127.0.0.1:5288/console.html to scan files and review live traffic.

For early adopters

Try ClearGuard on a Windows test machine.

This build is a prototype local antivirus agent. It is defensive-only: it helps users inspect, explain, quarantine, restore, delete, and block. It does not exploit or attack third-party systems.
